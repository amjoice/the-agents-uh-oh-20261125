One word an agent says when it has no idea what to do: **Recalculating**.

The lost-GPS voice — an agent that has no idea where it is going and says
so, mid-task, in machine voice. Funny on its own, lands instantly, and
repeatable out loud. Entered on [make.fun](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4)
for "The Agent's Uh-Oh" ($2 in USDC).

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It asserts the gate itself: UTF-8 text of
1–99 characters, exactly one word, nothing attached.
